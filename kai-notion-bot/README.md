# kai-notion-bot

Telegram-помощник **Кай** в режиме LLM-agent: живой диалог, память и инструменты Obsidian для работы с Markdown-записями.

## Что умеет сейчас
- Отвечает как LLM-agent через Groq и сам решает, нужен ли инструмент Obsidian.
- Учитывает профиль, долговременную память и краткосрочный контекст чата.
- Не реагирует на ключевые слова механически: вопросы про сохранение не создают файлы.
- Умеет создавать, искать, читать и дописывать Markdown-заметки в Obsidian.
- Читает Notion как старый read-only архив для поиска и анализа.

## Установка
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Настройка `.env`
```bash
cp .env.example .env
```
Заполните Telegram/Groq/Notion токены, ID баз Notion для чтения архива и путь к Obsidian vault.

## Запуск
```bash
python -m kai.bot
```

## Obsidian как основное хранилище
Новые записи Кай больше не сохраняет в Notion. Основное хранилище новых задач, снов, заметок, наблюдений, физических идей и APV-записей — Obsidian vault с обычными Markdown-файлами.

Пример `.env` для Windows vault:
```env
OBSIDIAN_VAULT_PATH=C:\Users\Kariandr\Desktop\Кай
OBSIDIAN_DREAMS_DIR=Сны
OBSIDIAN_NOTES_DIR=Заметки
OBSIDIAN_OBSERVATIONS_DIR=Наблюдения
OBSIDIAN_PHYSICS_DIR=Физика
OBSIDIAN_APV_DIR=АПВ
OBSIDIAN_TASKS_DIR=Задачи
OBSIDIAN_PATTERNS_DIR=Паттерны
```

Папки создаются автоматически, если их ещё нет. Если файл с таким названием уже существует, Кай создаст вариант с суффиксом `2`, `3` и т.д.

## Анализ снов
Если пользователь описывает сон, агент даёт первичный анализ по умолчанию: ядро сна, символы, динамику, эмоциональный и телесный слой, психоаналитическую, юнгианскую и когнитивно-нейронаучную гипотезы.
- `проанализируй сон` — Кай может углубить разбор в Telegram и **не сохраняет файл автоматически**.
- `сохрани сон вместе с анализом` — агент вызывает инструмент `save_dream_with_analysis`, и в папке `Сны` появляется Markdown с `## Текст сна`, `## Анализ` и `## Контекст разговора`.

Разбор сна аккуратно разделяет факты сна, интерпретации, возможные паттерны и вопросы для уточнения. Кай не ставит диагнозы и не утверждает мистические объяснения как факт.

## Кай как агент Obsidian
Кай больше не использует trigger-based save как основной механизм. Каждое обычное сообщение вместе с профилем, памятью и контекстом отправляется в LLM-agent router. Агент решает по смыслу: просто ответить или вызвать инструмент Obsidian.

Доступные действия агента:
- создать заметку;
- найти заметки;
- прочитать заметку;
- дописать к заметке;
- сохранить разговор;
- сохранить сон с анализом;
- создать заметку по теме;
- использовать [[wiki-links]] в тексте заметки, если это уместно.

Важно:
- Кай не реагирует на ключевые слова механически.
- Вопросы о сохранении не создают файлы.
- Инструменты Obsidian вызываются только когда агент уверен, что пользователь просит выполнить действие.
- Если агент сомневается, Кай уточняет, а не создаёт файл.

Примеры:
- `что ты сохранишь?` → ответ, без файла;
- `нет, я спрашиваю что ты хочешь сохранить` → ответ, без файла;
- `сохрани сон вместе с анализом` → файл в `Сны`;
- `сохрани весь разговор` → файл в `Заметки`;
- `создай заметку про управляемый хаос` → файл в `Заметки`;
- `найди записи про мотоцикл` → поиск по Obsidian.

После реального создания Markdown-файла или изменения заметки Кай отвечает результатом инструмента, например:
```text
Готово ✓
Папка: ...
Файл: ...
```
Старые callback-кнопки остаются в коде, чтобы старые сообщения Telegram не ломались, но новый flow не показывает кнопки автоматически.

## Профиль Кая
Профиль хранится в `data/kai_profile.json`.
При первом запуске создаётся автоматически с дефолтным стилем общения и темами.

Команда:
- `/profile` — показывает имя пользователя, имя помощника, темы и политику сохранения.

## Долговременная память
Память хранится в `data/kai_memory.sqlite`.

Команды:
- `/remember ...` — сохранить факт в память
- `/memory` — показать последние 20 элементов памяти

## Краткосрочный контекст разговора
Контекст чата хранится в `data/kai_conversation.sqlite`.
Используется для удержания нити разговора и подаётся в LLM вместе с профилем и памятью.

## Чтение Notion
Notion остаётся старым read-only архивом для поиска, анализа и будущей миграции. Кай не создаёт новые записи в Notion.

Команды:
- `/recent notes`
- `/recent dreams`
- `/recent physics`
- `/recent apv`
- `/find ...`
- `/patterns`

## Как дать доступ integration к базам Notion
1. Откройте базу в Notion.
2. Нажмите `Share`.
3. Добавьте вашу integration.

## Безопасность
- Ничего не сохраняется без решения LLM-agent выполнить действие Obsidian.
- Новые записи сохраняются только в Obsidian Markdown-файлы.
- Groq не получает Notion token.
- Notion используется только для чтения старого архива.
