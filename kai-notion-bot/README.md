# kai-notion-bot

Telegram-помощник **Кай** для быстрого сохранения текстовых заметок в базы Notion с обязательным подтверждением.

## Что умеет на этапе 1
- Принимает любое текстовое сообщение в Telegram.
- Локально классифицирует текст по правилам (без платных API).
- Создаёт черновик в SQLite.
- Показывает предложение сохранения: `[Сохранить] [Не сохранять]`.
- Отправляет в Notion **только** после нажатия `Сохранить`.

## Установка
1. Нужен Python 3.11+.
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Настройка `.env`
1. Скопируйте шаблон:
   ```bash
   cp .env.example .env
   ```
2. Заполните обязательные значения:
   - `TELEGRAM_BOT_TOKEN`
   - `NOTION_TOKEN`
   - ID нужных баз Notion

## Запуск
Из директории `kai-notion-bot`:
```bash
python -m kai.bot
```

## Как получить токены
### Telegram Bot Token
1. Откройте [@BotFather](https://t.me/BotFather).
2. Выполните `/newbot`.
3. Скопируйте токен в `TELEGRAM_BOT_TOKEN`.

### Notion Token
1. Откройте Notion: **Settings & members → Integrations → Develop your own integrations**.
2. Создайте integration.
3. Скопируйте `Internal Integration Token` в `NOTION_TOKEN`.

## Как дать доступ integration к базам Notion
1. Откройте нужную базу Notion.
2. Нажмите `Share`.
3. Добавьте созданную integration.
4. Повторите для каждой базы из `.env`.


## Что Кай понимает как команды
- `/start`, `/help`, `что ты умеешь`, `помощь` → показывает краткую справку.
- `ты работаешь`, `статус`, `ты жив` → сообщает текущий статус.
- `удали`, `удалить`, `сотри`, `убери запись`, `удали заметку`, `я уже записала`, `не надо сохранять` → безопасно объясняет, что авто-удаление пока не реализовано.
- `отмена`, `не сохраняй`, `забудь`, `не надо` → отвечает: `Окей, не сохраняю.`
- `привет`, `как дела`, `что делаешь`, `ты тут`, `спасибо`, `ок`, `поняла`, `ясно` → короткий smalltalk-ответ без сохранения.
- Всё остальное считается кандидатом на сохранение и проходит классификацию перед предложением кнопок.

## Примечание по безопасности
Кай ничего не сохраняет в Notion без явного подтверждения кнопкой `Сохранить`.
